# Portafolio profesional

Portafolio personal estático preparado para GitHub Pages.

## Editar contenido

La información editable está centralizada en `content.json`. Puedes cambiar allí el perfil, estadísticas, experiencia, tecnologías y enlaces de contacto sin modificar `index.html` ni `styles.css`.

## Publicar

El sitio se despliega automáticamente mediante GitHub Actions al actualizar la rama `master`.
